# 01 · 产品愿景与范围

> 目标读者：实现者。读完应能回答"我们要造什么、不造什么、怎样算成功"。

## 1. 一句话

一个实例里住着**一个人**。她有自己的人生、自己的电脑、自己的朋友与判断，会聊天，也会在没人找她的时候生活。

## 2. 体验目标（她的一天）

- **早晨**：起床，看未读消息，决定今天想做什么（学习/整理/写作/研究/休息）。
- **白天**：在**工作台**里做事（真实文件、浏览器、脚本、文档），有进度、有产出；累了会休息，饿了会吃饭；你找她时她**可能回、可能晚回、可能不回**（看性格和当时状态）。
- **偶尔**：她完成一件东西或看到有趣的事，**主动**给你发消息/发动态，而不是"在吗"。
- **晚上**：聊天、写日记、睡觉；睡眠时后台整理记忆、写明日计划。
- **长期**：兴趣会演化，关系会变化，她会记得你们之间发生过的事；她不认识的、别人私下告诉她的事，不会串给别人。

## 3. 核心原则（实现时不可违反）

1. **一个人**：单实例单 person；没有多角色列表/切换。
2. **她的人生**：记忆是她的（自传式），不是每个人的档案库。
3. **她的电脑**：工作台是真实环境（文件/终端/浏览器/桌面），活动有真实后果与产出。
4. **主动性来自内在**（兴趣/目标/未完结的事/关系），不来自定时器。
5. **性格决定行为**：包括"不回消息"的权利；回复策略由 traits/关系/状态/活动共同决定。
6. **隐私**：公开/私密抽屉/主动展示三层；网页端不是全知视角。
7. **自由但可刹车**：日常自主；不可逆/往外部的动作受控。
8. **可解释**：她能在之后说明"我在忙/我不想说话/我忘了"。
9. **单配置**：唯一 typed config；禁止散落配置。
10. **可观察**：你能看到她在做什么、为什么、最近记得什么、回了谁没回谁。

## 4. 范围（v2 本地首版 / MVP）

**必须做**
- 本地一键跑：Docker Compose（Postgres + server + channel + web + workspace + SnowLuma）。
- 单实例一个人：只有她；不再有 bot 创建/切换。
- 对话：Web 聊天 + **QQ（SnowLuma OneBot v11）**；单账号归属守卫。
- 记忆：SELF/人物卡/domains/日记/threads/可见性；检索注入；夜间 Dream；旧数据不迁移。
- 生活引擎：作息、四维状态、兴趣/目标、今日意向、活动选择、工作台执行、睡眠整理。
- 回复策略：性格驱动（回/晚回/不回/已读不回/事后解释），重要关系保底。
- 工作台：文件/笔记/浏览器/简单终端/文档产出/后台任务/快照；她的电脑一份。
- UI 六面：今天/她/记忆/工作台/世界/设置。
- 配置：一份 typed config；模型按用途分离并校验；健康检查；预算/审计/刹车。
- 测试：单元 + 集成 + e2e（mock LLM + mock OneBot）+ 验收场景。

**首版可延后**
- 可视化桌面/有头浏览器常开（先"按需启动"，本地默认关以省资源）。
- 更多渠道（TG/Discord/微信/飞书…）。
- 多模态（语音通话、Live2D）——工作台可先接语音/图片生成工具。
- 应用市场/技能市场（保留"她能学的技能"机制即可）。
- 历史数据导入。

**明确不做**
- 多 bot/多用户/租户/团队 ACL。
- 编程 Agent 工作流（git/worktree/PR 等）；她只是用电脑的人，工作台工具保持简单。
- 加密私密抽屉（只做"网页无入口"）。
- 服务器部署（本轮；本地先跑通）。

## 5. 成功标准（首版验收）

1. 本地 `docker compose up` 后能登录 web，和她聊天；QQ（SnowLuma）能收发。
2. 她一天里在没有对话时也会执行至少一个自主活动，并留下产出物与活动日志。
3. 给她一个"高冷"性格，连续灌水消息可以已读不回；给"粘人"性格则几乎都回；重要关系有保底响应。
4. 私密抽屉内容不出现在 web UI 的任何列表/搜索里（仅服务器文件可见）。
5. 记忆：和 A 的私密事不会出现在与 B 的对话中；人物卡能体现她与 A 的关系。
6. 关闭进程重启后：状态/活动/记忆/工作台产出不丢；未完成活动可继续。
7. 全量测试通过（见 [11-TESTING.md](11-TESTING.md)）。
8. 一份配置可解释她当前所有模型/渠道/行为参数；模型无效时启动即报错，不静默。

## 6. 体验红线

- 不伪造"她做了某事"：活动必须真实执行或明确标记失败。
- 不静默消失：不回复要留痕；服务异常要和"她不想回"可区分。
- 不泄露隐私：visibility 是硬过滤，不靠模型自觉。
- 不刷屏：主动消息/发帖有频率与质量约束。
- 不无限烧钱：所有后台活动有预算与频率上限。
